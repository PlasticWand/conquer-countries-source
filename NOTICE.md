# Conquer Countries: licences and credits

Conquer Countries (this repository, "Conquest") is a Roblox game that forks [OpenFront](https://github.com/openfrontio/OpenFrontIO). It is free software.

## Code: AGPL-3.0 with OpenFront's additional terms

The game's code is one program combining:

- **Code ported from OpenFront v0.35.2**, © OpenFront and Contributors, AGPL-3.0. Ported modules carry the header `-- Ported from OpenFront v0.35.2 (<original path>), © OpenFront and Contributors, AGPL-3.0. Modified for Roblox/Luau by the Conquest team.`
- **Code ported from [RoWorld](https://github.com/lukechatton/roworld) at commit 2be8efb**, © lukechatton and contributors, AGPL-3.0. Ported modules carry the header `-- Ported from RoWorld 2be8efb (<original path>), © lukechatton and contributors, AGPL-3.0. Modified for Conquest.`
- **The Conquest team's own code.**
- **colord** (colour maths in `src/client/Map/OpenFront/`), © 2020 Vlad Shilov, MIT License: see `src/client/Map/OpenFront/Colord-LICENSE.txt`.

The whole program is licensed under the **GNU Affero General Public License, version 3**, with OpenFront's additional terms under section 7: see [`LICENSE`](LICENSE). In short, those terms require modified versions to keep the notice "© OpenFront and Contributors" visible (the game shows it on its main menu, loading screen and credits), and not to use "OpenFront" as their title or imply OpenFront's endorsement.

**Getting the source of a published version:** the public repository [github.com/PlasticWand/conquer-countries-source](https://github.com/PlasticWand/conquer-countries-source) holds the code of every Roblox publish, tagged `place-v<N>`, where N is the place version the game's credits screen shows (`game.PlaceVersion`).
